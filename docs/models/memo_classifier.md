## Intended use
Label the free-text memo of a transaction with one of a closed set of categories, to give the case ranking model six memo counts.

## Human oversight
This model never closes, clears, files or dispositions anything.
A label is a ranking feature only; a person can relabel any memo and the person's label wins.

## Data

## Limitations
- The gold set is synthetic and labelled by the project team, not by investigators.
- The digest of the Ollama model is not stored: a different model under the same name would not be noticed.
- Memo text is untrusted: a rule layer catches known instruction-like text before any model call and the model only ever returns one of the fixed category names.
